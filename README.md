# حَدَق — المساعد الصوتي للمكفوفين وضعاف البصر

تطبيق Flutter بشاشة واحدة تعمل بالصوت، ومعه خادم ولوحة تحكم.

## المكوّنات

| المسار | ما فيه |
|---|---|
| `lib/core/intent.dart` | مصنّف النية العربي: سؤال، إعداد، طوارئ، أو جملة غير واضحة. يعمل دون إنترنت |
| `lib/app/controller.dart` | حالات الشاشة ومسارات كل نية |
| `lib/services/` | الصوت، الذاكرة المشفّرة، الكاميرا، الموقع، الخادم، النغمات والاهتزاز |
| `lib/ui/` | الشاشة الواحدة وكرة الصوت |
| `server/` | خادم Node فيه الإعدادات والتحديث الإجباري والمفاتيح والمستخدمون ووسيط الذكاء الاصطناعي، ولوحة التحكم على `/admin` |

## تشغيل الخادم ولوحة التحكم

```bash
cd server
npm install
npm start          # http://localhost:8787/admin
```

اسم المستخدم وكلمة المرور في `server/.env`: الحقلان `ADMIN_USER` و`ADMIN_PASSWORD`.
أضف `GEMINI_API_KEY` من صفحة «المفاتيح». يُحفظ المفتاح مشفّرًا ولا يصل إلى التطبيق.

## تشغيل التطبيق

```bash
# على هاتف Android متصل بالخادم المحلي (عنوان المحاكي 10.0.2.2، أو IP الكمبيوتر على الشبكة)
flutter run --dart-define=HADAQ_API=http://192.168.0.10:8787

# معرض الشاشات على الويب
flutter run -d chrome --dart-define=HADAQ_API=http://localhost:8787
```

بلا `HADAQ_API` يعمل التطبيق مستقلًا: الذاكرة والطوارئ والإرشاد تعمل، والمساعد يحتاج `--dart-define=GEMINI_API_KEY=...`.

## التحديث الإجباري

رقم البناء هو ما بعد `+` في `pubspec.yaml`، مثل `1.0.0+3`.
اختر «أدنى بناء مسموح» في اللوحة، فيُمنع كل إصدار أقدم منه ويُطلب منه التحديث. تبقى الطوارئ تعمل في كل الحالات.
